# Scope

## Грузим

- игроки: только GM (`/pub/titled/GM`), сейчас это 1719 логинов
- партии: только rated=true
- только rules=chess (без bughouse/crazyhouse/chess960)
- глубина истории: 24 месяца назад + ежедневный добор текущего месяца

## Источник

api.chess.com/pub, эндпойнты:
- /titled/GM - список игроков
- /player/{u}/games/archives - список месяцев
- /player/{u}/games/{y}/{m} - партии за месяц
- /player/{u}/stats - снапшот рейтинга

## Особенность источника

партия между двумя GM лежит в архивах обоих с одинаковым uuid — проверено руками на реальной паре игроков. Дедуп по uuid сделать на stage-слое.

## API

- без User-Agent тоже вроде отвечает, но всё равно всегда его шлём
- пауза между запросами 1 сек - ~30 запросов подряд, 429 не появилось
- ретраи на 429/5xx, без ретраев на 404

## Не грузим (пока)

не-GM игроков, партии старше 24 мес, unrated(в raw слой попадут, далее отфильтровать?), варианты шахмат, полный разбор PGN (спарсить только дебют)

## Объём

1719 игроков × 24 месяца, среднее число партий на игрока пока не мерил — надо прогнать на паре разных по активности игроков перед тем как называть цифры в README
